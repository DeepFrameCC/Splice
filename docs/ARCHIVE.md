# ARCHIVE — commandes non applicables au site Splice Studio (référencées pour plus tard)

Documentées ici pour ne rien perdre, sans bloquer le flux. Aucune n'est ignorée :
elle est simplement hors périmètre du site marketing aujourd'hui.

| Commande | Pourquoi N/A maintenant | Quand la réactiver |
|---|---|---|
| /aso | Splice Studio n'a pas d'app mobile (App Store / Play). | Si un jour une app/outil client est publié. |
| /paywalls | Aucun contenu premium gated pour l'instant. | Si templates/guides payants sont créés. |
| /team-onboarding | 2 fondateurs, pas de recrutement en cours. | À l'arrivée d'un nouveau membre. |
| /heapdump | Aucune fuite mémoire détectée à l'audit. | Si profil mémoire anormal en prod. |
| /remote-control | Accès remote non requis pour ces modifs. | Intervention prod multi-device. |
| /usage, /usage-credits, /extra-usage | Monitoring ops (Vercel/Neon/Cloudflare), pas du code site. | Suivi mensuel des coûts. |
| /reload-skills, /fewer-permission-prompts | Config d'environnement Claude Code, pas un livrable site. | Réglage de session. |
| /google-antigravity-sdk | Hors sujet pour un site vitrine/lead. GA4/GSC traités via /analytics. | Jamais, sauf besoin agent autonome. |
| /jarvis, /ia-core, /ia-cursor, /ia-rag, /ia-security, /claude-api | Outillage IA **interne** Splice Studio, distinct du site public. | Projet Jarvis dédié (repo séparé). |

> Les commandes IA internes (Jarvis, RAG, Claude API) sont légitimes mais
> appartiennent à un chantier « back-office Splice », pas au site splicestudio.fr.
> Les traiter ici diluerait le périmètre. À ouvrir comme projet à part.
